# Codex 本地连接使用说明

实际验证测试-非正式发布。当前源码候选尚未完成完整 Windows 编译与实机验收，本轮未生成新安装包。

## 用户流程

1. 安装 LocalBridge，并在已有 Codex 桌面客户端登录，无需另建 LocalBridge 账号。
2. 打开 LocalBridge，直接进入主界面。没有项目时仍可访问设置和诊断。
3. 点击“添加项目”，选择文件夹并输入名称，默认名称为文件夹名。
4. 首个项目自动启用；服务就绪后自动接入已有桌面客户端。
5. 在客户端刷新 MCP 连接或重启客户端后，打开新的本地聊天调用 LocalBridge。

服务状态、接入配置、客户端连接和真实工具调用分别显示。配置完成不等于实际调用成功；调用验证只提供状态信息，不再阻止进入主界面。

可保存多个中文名称项目，共用一套执行服务，同一时间只启用一个项目。后续添加只保存记录，点击列表中的“使用”切换；重新打开恢复上次活动项目。重命名只改变显示名称，不修改文件夹或重启服务，允许同名并按项目 ID 区分。重复添加相同目录保留原名称。移除只移除记录；移除当前项目会停用服务，不自动切换到其他目录。

模型仍由 Codex 联网调用；本地工具连接和执行在本机进行。无需 Tunnel ID 或 Runtime API Key，不增加聊天界面，不另装 Codex。

手动关闭 LocalBridge 后，适配器提示自行启动；不会暗中启动服务或重放写入请求。切换目录、模式或断开时，若有任务，先查看受影响任务并明确取消，等待终止确认。

新安装和旧测试版升级默认本地连接。连接配置升级只执行一次，此后保留用户选择；手动断开关闭自动接入，主动重新连接恢复自动接入。手动关闭服务会保持停止状态，重新打开不会覆盖这些选择。

Tunnel 放在设置中的“高级兼容连接”，原 Tunnel 设置和凭据保留。旧项目自动补齐名称；迁移前的原始配置另存为 `settings.json.schema-*.bak` 和 `connection-profile.schema-1.bak`。

## 配置问题

- 同名 `localbridge` 条目不属于当前安装：提示冲突，保留原配置。
- 配置不可写或读回核验失败：显示失败，保留备份，不标为配置完成。
- 本安装条目被停用：先断开，再重新接入。
- CODEX_HOME 已改变：先点击断开，处理记录中的旧目录，再接入新目录。
- 配置记录属于另一安装：拒绝移除，使用原安装管理其条目。
- Codex 桌面程序缺失：先安装并登录，然后重新检测。

备份文件使用 `config.toml.localbridge-*.bak`；连接记录不包含内部认证凭据。断开只移除能够核实归属的 LocalBridge 条目，其他 MCP、模型设置和登录信息保留。

## 开发与后续验收

完整 Windows 构建需要原 Rust 1.85、MSVC 与 Windows SDK 环境。资源准备会独立构建、暂存并记录 `localbridge-mcp.exe` 的 SHA256，与 Broker 一同纳入安装内容检查。开发运行前需构建适配器到 `src-tauri/target/debug/localbridge-mcp.exe`；发行版从安装目录加载随包适配器。
