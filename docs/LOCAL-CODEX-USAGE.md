# Codex 本地连接使用说明

实际验证测试-非正式发布。当前源码候选尚未完成完整 Windows 编译与实机验收，本轮未生成新安装包。

## 用户流程

1. 安装并登录 Codex 桌面程序。
2. 启动 LocalBridge，选择本地工作目录。
3. 选择权限，默认编辑模式；管理员模式继续使用原有确认与 Broker。
4. 服务就绪后点击“连接 Codex”。
5. 在 Codex 新会话中要求 LocalBridge 列出所选目录。收到真实工具结果后完成引导。

“服务就绪”“配置完成”“客户端已连接”分别显示，含义不同。引导还检查成功工具调用是否经过本地路线。配置完成后客户端仍可能需要新会话加载 MCP。

模型仍由 Codex 联网调用；本地工具连接和执行在本机进行。无需 Tunnel ID 或 Runtime API Key，不增加聊天界面，不另装 Codex。

手动关闭 LocalBridge 后，适配器提示自行启动；不会暗中启动服务或重放写入请求。切换目录、模式或断开时，若有任务，先查看受影响任务并明确取消，等待终止确认。

旧用户保持 OpenAI Tunnel 模式，可在连接设置中改为本地。切回高级兼容模式时继续使用原 Tunnel 设置和凭据。

## 配置问题

- 同名 `localbridge` 条目不属于当前安装：提示冲突，保留原配置。
- 配置不可写或读回核验失败：显示失败，保留备份，不标为配置完成。
- 本安装条目被停用：先断开，再重新接入。
- CODEX_HOME 已改变：先点击断开，处理记录中的旧目录，再接入新目录。
- 配置记录属于另一安装：拒绝移除，使用原安装管理其条目。
- Codex 桌面程序缺失：先安装并登录，然后重新检测。

备份文件使用 `config.toml.localbridge-*.bak`；连接记录不包含内部认证凭据。断开只移除能够核实归属的 LocalBridge 条目，其他 MCP、模型设置和登录信息保留。

## 开发与后续验收

完整 Windows 构建需要原 Rust 1.85、MSVC 与 Windows SDK 环境。资源准备会独立构建、暂存并记录 `localbridge-mcp.exe` 的 SHA256，与 Broker 一同纳入安装内容检查。开发运行前需构建适配器到 `src-tauri/target/debug/localbridge-mcp.exe`；发行版从安装目录加载随包适配器。
