把当前 ChatGPT 聊天接到这台电脑

安装包已携带配套扩展。首次安装在 LocalBridge 点击“准备配套扩展”，无需去 GitHub 找 ZIP，也无需填写 API Key、Tunnel ID 或安装 Codex 桌面程序。

按顺序完成六步

  1. 准备本机。安装同次构建的 LocalBridge 安装包，打开应用，选择允许使用的项目文件夹，并启动本地服务。网页接入使用“本地连接”模式。
  2. 准备扩展文件。打开 设置 → ChatGPT 网页 → 开始设置，选择 Edge 或 Chrome，点击 准备配套扩展（推荐）。看到文件准备完成后继续；这时浏览器尚需手动加载。
  3. 在浏览器加载。复制下面的管理页地址，粘贴到浏览器地址栏并按回车。开启“开发者模式”，点击对应加载按钮，选择应用提供的固定加载目录。目录内应有 manifest.json；不要选择下载的 ZIP、下载目录或其上一级文件夹。
浏览器地址栏输入加载按钮
Microsoft Edgeedge://extensions加载解压缩的扩展
Google Chromechrome://extensions加载已解压的扩展程序

按钮名称可能随浏览器版本或语言略有变化；选择手动加载解压目录的按钮。

  1. 连接并批准配对。打开或刷新 https://chatgpt.com 并登录。点击浏览器工具栏“扩展”，找到 LocalBridge 并固定；点击 LocalBridge →“连接这台电脑”。回到 LocalBridge → 设置 → ChatGPT 网页，核对请求中的项目文件夹与权限，再点击“批准配对”。
  2. 启用当前聊天。返回扩展，点击“为此聊天启用工具”（等待配对时为“我已批准，启用此聊天”）。看到 当前聊天已启用 才完成这一步。刷新或切换聊天后重新启用；切换项目后重新核对授权。
  3. 完成首次只读调用。在扩展点击“准备首次只读调用”。检查聊天输入框中的工具说明和测试提示，再手动发送。助手产生请求后，核对工具为 workspace_context 及其参数，点击“确认执行以上请求”。看到实际结果与“已完成真实调用”后，点击“填入结果”，检查内容并手动发送。

文件已准备、浏览器已连接、配对已批准、当前聊天已启用、工具实际成功是不同阶段。当前聊天的状态以扩展窗口为准，应用里的数量是本机总计。

单独下载或手动导入

本项目发行源为 MYD548-svg/LocalBridge-Community Releases。下载 LocalBridge-ChatGPT-Web-v<版本>.zip 并在应用导入。不要下载 Source code ZIP；Actions 候选附件解压后再选择里面真正的扩展 ZIP。

本版本尚未正式发布、附件缺失或与当前应用不匹配时，应用会说明原因。使用内置包即可首次准备；不要用其他项目的扩展替代。

升级：先关闭，导入后重新加载

  1. 在所有扩展窗口点击“停止并断开”，等待执行停止。
  2. 在浏览器扩展管理页关闭 LocalBridge 开关。
  3. 回到应用，明确确认替换扩展文件，再准备新版或导入配套 ZIP。较旧内置包不能覆盖已准备的新版。
  4. 回到浏览器管理页，重新启用/重新加载 LocalBridge，刷新 ChatGPT。
  5. 重新连接并启用当前聊天；项目或授权发生变化时重新核对配对。

固定目录 %LOCALAPPDATA%\LocalBridge\browser-extension\current 请保留。导入成功后，下载的 ZIP 可以不再保留。应用保留更新备份。

遇到问题时

  • 没有配对请求：浏览器加载后，还需要到 ChatGPT 点击扩展里的“连接这台电脑”。检查应用已选择项目、服务就绪且使用本地连接。
  • 提示宿主缺失或版本不兼容：安装本项目的配套新版安装包。只导入 ZIP 无法补齐旧安装包缺少的浏览器宿主。
  • 输入框有草稿：先保存或发送草稿，再填入说明或结果。应用不会覆盖原草稿。
  • 配对已撤销：在扩展帮助中重置配对身份，再申请并核对授权。
  • 企业策略禁止手动加载：联系设备管理员。
  • 执行结果未知：先核查实际结果；扩展不会自动重发该请求。

工具在本机执行；你确认回填并发送的内容会进入在线聊天。
