安装、更新与恢复
  1. LocalBridge → 设置 → ChatGPT 网页 → 准备配套扩展。
  2. 在 Edge/Chrome 扩展管理页开启开发者模式，加载应用提供的固定目录；导入 ZIP 只是准备文件。
  3. 到 ChatGPT 点击“连接这台电脑”，回应用批准配对，再回来启用当前聊天。

首次安装无需 API Key、Tunnel ID 或 Codex 桌面程序。找不到图标时在浏览器“扩展”菜单固定 LocalBridge。

升级前停止并断开工具、关闭浏览器中的扩展开关。在应用准备新版后，重新启用/重新加载扩展并刷新 ChatGPT。

刷新或切换聊天后重新启用；切换项目后重新核对授权。撤销配对后重置身份再申请。企业策略禁止手动加载时联系设备管理员。
